## Nguyên tắc tham chiếu

- Áp dụng interaction phù hợp, không sao chép branding/UI assets hoặc toàn bộ scope.
- Nguồn thiếu full body (TickTick Focus, camelcamelcamel) được ghi rõ; không dùng nó để khẳng định chi tiết chưa kiểm chứng.
- DevToys là desktop product; áp dụng input/options/output vào web module, không khẳng định web app tương đương đã được test.
- camelcamelcamel không cung cấp bằng chứng về Shopee provider; AnyList không chứng minh order/warranty lifecycle.
- Google Docs/Notion có behavior khác Nexora; manual Save, no collaboration, folder/parent immutability và lifecycle User đã duyệt luôn thắng.
