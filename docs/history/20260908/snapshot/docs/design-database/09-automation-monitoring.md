## automation.Definition

Owner automation pointer to immutable approved definition version. Profile **R**. Status: **Proposed: Q-07**.

| Field | SQL Server type | Nullable | Meaning / validation | Key / default / reference |
| --- | --- | --- | --- | --- |

| UpdatedAt | datetime2(7) | No | Server write instant, initially CreatedAt | No implicit default unless stated |
| UpdatedByUserId | uniqueidentifier | Yes | Actual most recent actor; null only system/anonymized identity | FK UpdatedByUserId → Id; [identity.User](02-core-identity-platform.md#identity-user); NO ACTION |
| RowVersion | rowversion | No | SQL-generated 8-byte optimistic concurrency token; not content history or clock | DB generated; exclude from inserts/updates |
| Title | nvarchar(200) | No | Workflow name | No implicit default unless stated |
| CurrentVersion | bigint | No | Latest saved definition | No implicit default unless stated |
| Enabled | bit | No | Execution availability | No implicit default unless stated |
| State | varchar(64) | No | Draft, Ready, Invalid, Disabled | CHECK allowed codes documented in meaning |
| TrashBatchId | uniqueidentifier | Yes | Owner Trash | FK (OwnerId, TrashBatchId) → (OwnerId, Id); [operations.TrashBatch](04-files-jobs-notifications.md#operations-trashbatch); NO ACTION |

**Keys/index candidates:** PK(Id) nonclustered; internal clustering strategy in conventions. UQ(OwnerId,Id); IX(OwnerId,CreatedAt,Id). IX OwnerId,Enabled,State

**Integrity / transaction:** Disable stops new effects after authority recheck; running external effect cannot be rolled back by UI. Graph scope/action catalog Q-07.

**Lifecycle / classification:** All writes check RowVersion; lifecycle guard also applies to import, automation, bulk and restore. Same-owner FK(OwnerId,Id) to Resource registry identity; payload and registry lifecycle commit atomically. Payload classification defaults Private owner; credential/encrypted/hash columns are never list/search/log data. [Per-field classification](15-field-classification.md#automation-definition). No ON DELETE CASCADE; approved purge service orders dependencies, rejects live references, preserves minimal audit. User-owned Trash retention is not inferred from job-log retention.
