## M01 — goal của slice đầu, không thay toàn phase

Nguồn có authority cụ thể hơn roadmap cho slice: [M01](../delivery/milestone-01/README.md), [stories](../delivery/milestone-01/01-stories.md), [readiness](../delivery/milestone-01/06-readiness-and-evidence.md). `Sxx`/`ACxx` bên dưới là ID trong gói M01, không tạo requirement mới.

| Goal ID | Stories / expected outcome | Runtime evidence cần có |
| --- | --- | --- |
| NXG-M01-01 | S00–S01: clean local toolchain và bootstrap an toàn. | Doctor/pins/lockfiles; concurrent bootstrap; no default credentials; audit redaction. |
| NXG-M01-02 | S02–S04: register/verify/login/logout/reset password-only. | One PersonalSpace + grants atomic; expiry/replay/resend/enumeration; CSRF/session; reset không auto-login/MFA bypass/undelete. |
| NXG-M01-03 | S05–S06: profile vi/en/timezone và quản lý own sessions. | Strong ETag/stale tabs; foreign-session 404; revoke-all gồm current session; locale không đổi instant/currency. |
| NXG-M01-04 | S07–S09: metadata administration, role/action/module preview và mutation đúng scope. | Metadata allowlist; last-SA race; stale preview; deny/paused/dependency rules; default grant future-only, disable giữ data. |
| NXG-M01-05 | S10–S11: durable security notifications và local recovery/clean checkout. | Three-channel outcomes, crash/dedupe/Unavailable; isolated restore/runbook thực chạy, không fake Sent. |

G01 implementation approval vẫn cần cho toàn bộ stories; G02–G06 theo matrix nguồn. M01 **không** gồm full Notification Center, Files/avatar, Sharing/Support/Emergency, Vault/business modules, self-delete UI/restore, MFA enrollment/recovery hoặc outbound ingestion. Các capability đó vẫn nằm trong mục tiêu rộng hơn và không bị loại khỏi R1.
