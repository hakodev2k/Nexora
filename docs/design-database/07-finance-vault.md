| RowVersion | rowversion | No | SQL-generated 8-byte optimistic concurrency token; not content history or clock | DB generated; exclude from inserts/updates |
| Title | nvarchar(200) | No | Account name | No implicit default unless stated |
| Kind | varchar(64) | No | Cash, Bank, Wallet, Other | CHECK allowed codes documented in meaning |
| Currency | char(3) | No | Explicit ISO currency, immutable after first posted entry | Uppercase registered currency; no float |
| OpeningAmount | decimal(28,8) | No | Signed opening balance proposal | No implicit default unless stated |
| OpeningDate | date | No | Effective opening day | No implicit default unless stated |
| Status | varchar(64) | No | Active, Closed | CHECK allowed codes documented in meaning |

**Keys/index candidates:** PK(Id) nonclustered; internal clustering strategy in conventions. UQ(OwnerId,Id); IX(OwnerId,CreatedAt,Id). IX OwnerId,Status,Title

**Integrity / transaction:** Displayed balance derived from opening plus posted signed legs, never mutable cached input. Reconciliation, closing and corrections require Q-05.

**Lifecycle / classification:** All writes check RowVersion; lifecycle guard also applies to import, automation, bulk and restore. Same-owner FK(OwnerId,Id) to Resource registry identity; payload and registry lifecycle commit atomically. Payload classification defaults Sensitive personal; credential/encrypted/hash columns are never list/search/log data. [Per-field classification](15-field-classification.md#finance-account). No ON DELETE CASCADE; approved purge service orders dependencies, rejects live references, preserves minimal audit. User-owned Trash retention is not inferred from job-log retention.
