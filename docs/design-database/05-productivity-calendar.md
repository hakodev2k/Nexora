## productivity.Project

Personal project and terminal locking boundary. Profile **R**. Status: **Technical decision**.

| Field | SQL Server type | Nullable | Meaning / validation | Key / default / reference |
| --- | --- | --- | --- | --- |
| Id | uniqueidentifier | No | PK and same identity as platform.Resource.Id; generated by trusted command | No implicit default unless stated |
| OwnerId | uniqueidentifier | No | Required isolation boundary resolved server-side, immutable | FK OwnerId → Id; [platform.PersonalSpace](02-core-identity-platform.md#platform-personalspace); NO ACTION |
| CreatedAt | datetime2(7) | No | Server insert instant, DEFAULT SYSUTCDATETIME() | No implicit default unless stated |
| CreatedByUserId | uniqueidentifier | Yes | Actual actor for attribution, not owner; null only system/anonymized identity | FK CreatedByUserId → Id; [identity.User](02-core-identity-platform.md#identity-user); NO ACTION |
| UpdatedAt | datetime2(7) | No | Server write instant, initially CreatedAt | No implicit default unless stated |
| UpdatedByUserId | uniqueidentifier | Yes | Actual most recent actor; null only system/anonymized identity | FK UpdatedByUserId → Id; [identity.User](02-core-identity-platform.md#identity-user); NO ACTION |
| RowVersion | rowversion | No | SQL-generated 8-byte optimistic concurrency token; not content history or clock | DB generated; exclude from inserts/updates |
| Title | nvarchar(200) | No | Required nonblank display title | No implicit default unless stated |
| Description | nvarchar(max) | No | Required nonblank description up to20000characters | No implicit default unless stated |
| StartAt | datetime2(7) | No | Required scheduled start | No implicit default unless stated |
| EndAt | datetime2(7) | No | Required scheduled end | No implicit default unless stated |
| Status | varchar(64) | No | NotStarted, InProgress, Completed, Skipped | CHECK allowed codes documented in meaning |
| Priority | tinyint | Yes | 0 highest through 3 lowest | No implicit default unless stated |
| Color | nvarchar(30) | Yes | Approved palette token | No implicit default unless stated |
| Icon | nvarchar(100) | Yes | Emoji/builtin icon, mutually exclusive color | No implicit default unless stated |
| Notes | nvarchar(max) | Yes | Optional owner notes | No implicit default unless stated |
| Revision | bigint | No | Increment for every semantic change | No implicit default unless stated |
| TerminalAt | datetime2(7) | Yes | Irreversible close instant | No implicit default unless stated |
| TrashBatchId | uniqueidentifier | Yes | Current deletion batch | FK (OwnerId, TrashBatchId) → (OwnerId, Id); [operations.TrashBatch](04-files-jobs-notifications.md#operations-trashbatch); NO ACTION |

**Keys/index candidates:** PK(Id) nonclustered; internal clustering strategy in conventions. UQ(OwnerId,Id); IX(OwnerId,CreatedAt,Id). IX OwnerId,TrashBatchId,Title,Id; IX OwnerId,Status,StartAt,EndAt

**Integrity / transaction:** EndAt > StartAt; Color XOR Icon; Status defaults NotStarted. Completed/Skipped never reopened; all Task mutations blocked. Complete with open Tasks needs confirmation+reason; Skip confirms terminal lock but does not require completion reason or change child states.

**Lifecycle / classification:** All writes check RowVersion; lifecycle guard also applies to import, automation, bulk and restore. Same-owner FK(OwnerId,Id) to Resource registry identity; payload and registry lifecycle commit atomically. Payload classification defaults Private owner; credential/encrypted/hash columns are never list/search/log data. [Per-field classification](15-field-classification.md#productivity-project). No ON DELETE CASCADE; approved purge service orders dependencies, rejects live references, preserves minimal audit. User-owned Trash retention is not inferred from job-log retention.
