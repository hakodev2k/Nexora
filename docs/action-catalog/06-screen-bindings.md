## UI-only interactions

Search/filter/sort/pagination dùng lại QUERY cùng scope; đổi view/collapse/focus/hover không tạo permission row. Drag Task đổi cột dùng transition, trong cột dùng reorder; keyboard menu giống hệt. Copy dữ liệu đã load không tạo server read mới nhưng vẫn yêu cầu current source capability; không coi client clipboard là boundary có thể thu hồi dữ liệu đã đọc.

File picker, tag picker, share dialog, reminder field và version restore dùng composition rules; không auto-grant dependencies. Project/Task share được truy cập qua shared route nhưng owner history không có share binding.
