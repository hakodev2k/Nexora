# UX-12 — Security & Sensitive Data UX

Mask secrets by default. Reveal and Copy are explicit and separately permissioned.

Protected values never appear in URLs, notifications, analytics, logs, global search snippets, browser persistent storage or generic errors.

Vault reveal is time-limited; Copy does not imply reveal. Support/Emergency cannot reveal/copy/export.

Finance reports never create misleading mixed-currency totals.

Provider content is untrusted and sanitized. Provider errors never become fake zero price, out-of-stock or empty success.

Support/Emergency always show persistent user/module/expiry/read-only context.
