# UX-11 — Accessibility

Minimum acceptance:
- full keyboard primary flows;
- visible focus;
- no drag-only action;
- proper labels/error association;
- accessible names for icon controls;
- status not color-only;
- accessible table headers;
- charts have text/table equivalent;
- dialog focus trap and focus return;
- comfortable touch targets;
- WCAG AA contrast intent;
- reduced motion;
- accessible loading status;
- destructive confirmation not distinguished by color alone.
