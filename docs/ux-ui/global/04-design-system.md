# UX-04 — Design System Foundations

Direction: **calm, neutral, productivity-first, data-capable**.

Avoid heavy glassmorphism, decorative gradients as hierarchy, oversized cards for dense data, per-module brand colors, and color-only status.

Typography roles: page title, section heading, body, compact table/list, metadata, monospace.

Spacing uses a 4px base scale. Dense data views may be tighter; reading/editor views are more spacious.

Elevation is reserved for overlays, menus, drawers and dialogs.

Required semantic roles: primary/secondary/muted text, surfaces, borders/focus, success/warning/danger/info, shared status tokens.

Density:
- Content: Documents, News, Resume.
- Data: Finance, Vault, Assets, Admin.
- Flow: Projects, Calendar, Automation.
