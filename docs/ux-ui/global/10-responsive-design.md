# UX-10 — Responsive Design

Baseline:
- Mobile 360–767
- Tablet 768–1199
- Desktop ≥1200

Patterns:
- multi-pane → stacked navigation on mobile;
- tables → priority rows/cards;
- toolbar → primary action visible, secondary controls in sheet/overflow;
- Calendar favors Day/Agenda on narrow screens;
- Documents prioritize editor content width.

Viewport changes must not discard safe unsaved form state, filters, sort or current resource context.
