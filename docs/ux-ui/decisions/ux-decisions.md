# UX-16A — Resolved Delegated UX Decisions

1. Global sidebar groups modules by domain.
2. Global search/command palette uses Ctrl/Cmd+K.
3. Desktop supports optional context panel for browse→inspect.
4. Mobile bottom nav baseline is Home / Search / Create / Inbox / More.
5. Forms use explicit Save and dirty guard unless feature says otherwise.
6. Field validation inline; safe correlation ID on unexpected errors.
7. Provider unavailable/stale is separate from empty.
8. Data tables favor compact density and sticky headers.
9. Drag always has keyboard/menu equivalent.
10. Admin/Support/Emergency use distinct persistent context.
11. Search never exposes Vault payload.
12. Cards show decision-driving metadata only.
13. Destructive vocabulary is standardized.
14. Content-heavy screens may collapse navigation for focus.
15. Reference products never introduce team/workspace concepts.
