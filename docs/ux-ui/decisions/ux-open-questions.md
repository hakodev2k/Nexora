# UX-16B — Major UX Questions

This mirrors major product decisions; it does not replace the source queue.

- **Q-01:** Account deletion/portability — waiting/cancel/export UX.
- **Q-02:** MFA/recovery/recent-auth — enrollment and sensitive-action gates.
- **Q-03:** Sharing/sensitive projections — existing-link behavior and safe fields.
- **Q-04:** Vault recovery/portability — recovery, encrypted I/O, support safe metadata.
- **Q-05:** Finance semantics — budget, FX, debt, correction/deletion, savings.
- **Q-06:** Shopee provider/price contract — provider, variant, currency, polling/freshness.
- **Q-07:** Automation/network scope — graph depth, catalog, mapping, egress.
- **Q-08:** Capacity/retention/operations — quota, long operations, backups/logs.
- **Q-09:** Language/locale — UI languages, currency, first day of week.
- **Q-10:** Productivity extensions — subtasks, reminders, recurrence, attachments.
- **Q-11:** Documents/Resume formats — import/export/fidelity/assets.
- **Q-12:** Interview↔Calendar ownership — linked Personal Event vs new source.

Any UX depending on these remains Proposed/Blocked.
