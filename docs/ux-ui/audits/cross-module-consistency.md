# Cross-module UX Consistency Audit

## P0
1. **Identity provisioning timing:** registration should present Pending Verification and not imply fully active personal space before canonical activation behavior is synchronized.
2. **Share expiry:** 7-day default is proposal while exposure/security decision remains open.
3. **First day of week:** Planner/Calendar must not hard-code Monday while Q-09 is open.
4. **Vault operator ambiguity:** reject any cross-user “SuperAdmin reveal”; Support/Emergency expose no Reveal/Copy/Export.

## P1
5. Older roadmap wording can be stale; UX follows authority order and records conflict instead of rewriting source.
6. Dashboard exact default widgets/customization remain Proposed.
7. News UI can be designed but ingestion source must not be presented as approved while decision remains open.
8. Assets/Career/Learning screen architecture can be delegated while field/state/lifecycle details remain product-discovery dependent.

## Normalization
- Global sidebar groups modules.
- Explicit Save is shared.
- Canonical destructive wording fixed.
- Provider failure ≠ empty.
- Read-only always explains why.
- Global search excludes Vault payload.
- Drag has keyboard/menu alternative.
- Admin/Support/Emergency are distinct contexts.
