## Renewal and retention

Record renewal requires explicit RenewedOn/NewExpiry dates, NewExpiry>=RenewedOn, optional exact nonnegative Amount/currency and private Notes<=2,000. Append an owned RenewalRecord containing the old entered date and new entered date; update root ExpiresOn and optional recorded cost atomically. It does not overwrite observed values, Certificate.NotAfter, explicit Canceled flag or other subtype metadata; confirm says only the Nexora record changes and no charge/provider renewal occurs. No requirement to extend the prior date is invented; corrections can retain an earlier previously-entered expectation as history. RenewedOn is the owner-entered actual day, CreatedAt is the server recording instant. No renewal update/delete action is fabricated.
