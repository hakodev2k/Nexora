## Bounded implementation contract

Foundation binds P06-AUT-001/002/011/012 and FX-34-BR-001/006, AC003; goals NXG-FX34-G02/G03 and NXG-SYS-03/08/14. Chosen first topology: ordered linear sequence,1–20 steps, no branch/loop/expression/script. Step IDs unique positive integers. Input bindings are typed literals only; no trigger/body/previous-output interpolation. Extending mappings/conditions requires a versioned contract, not arbitrary evaluation.

Closed trusted registries: trigger `manual` version1; action `tasks.task.create` version1 from FX12, module `Tasks`. Subsequent schedule/module-event/webhook triggers and further approved module actions are remaining scope, not silently enabled by these registries. Unknown keys/versions and extra fields fail closed. The initial action is a private local Task creation contract; no provider transport, purchase, privilege action, deletion or external notification action.

Wire shape: object exactly `schemaVersion:1`, `trigger:{key:"manual",version:1}`, `steps:[{id:positiveInt,action:{key:"tasks.task.create",version:1},inputs:{projectId:nonemptyGuid,title:string,startAt:offsetTimestamp,endAt:offsetTimestamp,priority:"P0"|"P1"|"P2"|"P3",description?:string|null}}]`. Offset timestamps use invariant round-trip `O` format. Title trimmed1–200 UTF-16 units; optional description≤4000; valid scalar text, no controls; end strictly after start. Task status is NotStarted; no reminder, tags, acceptance criteria, rank override or hidden parent-time confirmation in this action version. Actual parent lifecycle/time bounds and current owner/action/resource authority are checked by the existing Task command at eventual dispatch.

JSON input≤64KiB UTF-8, parser depth8, no comments/trailing commas/duplicate properties. These are engineering parser bounds, not provider budgets. Errors contain fixed codes/messages, never input text or raw JSON. Parsed records are immutable and contain no OwnerId/session/credential/secret fields. No secret references are supported by this action version; injected values fail schema validation.

Shape parsing does **not** mean application validation, approval, enablement or execution readiness. Catalog contribution currently has execution availability=false and verified simulation=false. DryRun is rejected. Before enable/dispatch: SQL-backed immutable definition version, current account/PersonalSpace/module/action/dependency/parent-resource authority, runtime contribution availability and durable dedupe/lease/audit contracts must all pass. No caller Boolean or parsed JSON can supply authority. No run/UI/API handler or migration is installed by this foundation.
