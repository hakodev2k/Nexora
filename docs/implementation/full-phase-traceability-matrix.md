## Status vocabulary and reading rule

Only the following values are used in the `Status` column: `Specified`,
`Approved to implement`, `Implemented`, `Runtime verified`, `Accepted`,
`Partial`, `Blocked`, `Paused`, `Not implemented`, and `Not run`.

`Partial` means a bounded local subset exists while one or more committed
requirements/actions remain absent. `Implemented` means the named bounded
slice has source coverage; it does not imply SQL/browser/runtime verification.
`Blocked` means a required contract or network/operations gate is still open;
`Paused` is a Product Owner pause. Existing test references are evidence only
when the command ran on the exact revision; the code-only amendment prevents
adding new test suites or fixtures in this run.

The first incomplete product phase is **P01 Core Platform**. FX04 Sharing,
FX05 Support/Emergency, FX07 Files and FX10 Transfer remain the critical path;
later phases stay traceable but cannot be called complete while P01 is partial.
