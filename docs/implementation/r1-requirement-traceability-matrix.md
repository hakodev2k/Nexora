  this matrix does not imply runtime verification.
- `Partial`: only the named bounded slice exists; the feature's remaining
  actions are still gated or unimplemented.
- `Not implemented`: no usable source slice is present.
- `Blocked`: implementation is held by a missing contract or network/ops gate.
- `Paused`: Product Owner pause remains effective; no real provider execution is
  enabled.
